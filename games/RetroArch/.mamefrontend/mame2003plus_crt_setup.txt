MAME2003Plus CRT output
======================

The UI is native 320x240. These files are MiSTer.ini section snippets;
merge one [MENU] section into the existing /media/fat/MiSTer.ini.
Do not replace your MiSTer.ini with a snippet.

15 kHz NTSC Analog I/O board:
  mame2003plus_crt_15k.ini
  Select RGB/SCART or component/S-Video through the existing global MiSTer
  settings. For RGB SCART, use composite_sync=1.

15 kHz NTSC Direct Video DAC:
  mame2003plus_crt_15k_directvideo.ini
  Requires a compatible VGA DAC. Component needs sync-on-green support.

15 kHz PAL:
  mame2003plus_crt_15k_pal.ini
  This is 15.625 kHz / 50.08 Hz; the 320x240 UI is centered in 288 lines.

31 kHz VGA CRT:
  mame2003plus_crt_31k.ini
  Uses 640x480@60 and doubles the UI to 640x480.

15 kHz NTSC timing: 320x240 active, 15.735 kHz horizontal, 60.06 Hz vertical.
The mode is core-specific; launched MRA games retain their normal timings.
Connection-specific global settings are preserved by the snippets. For a
Direct Video DAC, keep direct_video=1 in the relevant [MENU] section.

If a CRT shows moving noise, it is receiving the raw background generated by
the Menu-derived RBF. Set vga_scaler=1 and use the matching video_mode snippet
so MiSTer routes the Linux framebuffer to the CRT.
